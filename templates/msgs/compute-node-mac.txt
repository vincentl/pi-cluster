Compute Node Setup - Repeat for each node

  - Boot compute node
  - `ssh {{cluster.user}}@{{@.head-node}}`
  - Run `ip addr show eth0 | grep ether | sed -E 's/.*ether (([0-9a-f]{2}:){5}[0-9a-f]{2}).*/mac.NNN = "\1"/'`
    - Add the line to the `[node]` section of the cluster.toml file
    - Update the `NNN` characters to the node number: 001, 002, ...
  - Run `sudo raspi-config`
    - Choose Menu 6 > A4 Boot Order > B3 Network Boot
    - Press ESC key to Finish
  - Run `sudo shutdown now`
