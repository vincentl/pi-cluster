## Useful from the last sessions

- On this Mac, `git show HEAD` is ambiguous (`HEAD` matches `head/`); use `@` or `HEAD --`.
- In a script fed to `ssh pi-login 'bash -s' <<'EOF'`, `srun` and a nested `ssh` read standard
  input and swallow the rest of the script: give `srun` `</dev/null` and `ssh` `-n`.
- `ethtool`, `swapon` and `slurmd` are in `/usr/sbin`, not on `pi`'s PATH over ssh: call them by
  full path in checks.
- Vincent's Lima VM `osoe` runs Debian trixie (bash 5.2.37, systemd 257.13), good for checking
  bash logic and unit files (`systemd-analyze verify`, `systemctl --root=… enable`) without the
  cluster. It cannot see the scratchpad: stream files in with `tar`, and never run `head/`
  scripts there (`lib.sh` stops off a Pi anyway).
- Mermaid previews: headless Chrome (`--headless=new`, a throwaway `--user-data-dir`) renders a
  local page that loads Mermaid 11 from jsdelivr; it writes the screenshot but does not exit, so
  stop it afterwards. mermaid.live renders `/edit#pako:` links in the browser. Different Mermaid
  versions order a flowchart's nodes differently; the overview pins the order with a subgraph
  and invisible links.
- Photos: `magick` converts and strips metadata; the figure list has the commands. Nodes 1-2
  carry the earlier PoE HAT (F), fan always on, about 29 °C idle; nodes 3-4 the Rev1.2, fan run
  by the Pi, off below 50 °C, about 48-50 °C idle.
- Research for plans went to background agents or direct fetches, citing primary sources
  (Debian source files, Slurm docs for 24.11.5, kernel trees); every fact is a row in the plan
  with its URL.
